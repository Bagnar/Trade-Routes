# CLAUDE.md — контекст проекта для Claude Code

Читай этот файл первым. Общайся с основателем по-русски; код, идентификаторы и комментарии — по-английски.

## Что это за проект

Бесплатный информационный портал о правилах международной торговли для начинающих торговцев и поставщиков: любая пара стран, любая товарная группа HS-6, законы и органы, экспортный контроль (решение 12 сентября 2026, план — `docs/expansion-plan.md`; справочники загружаются заранее, страницы собираются по запросу). Запрос: «Везу [товар HS-6] из [страны] в [страну] как [партию | посылки]». Ответ: страница коридора — правила вывоза и ввоза, что заплатить обоим государствам, соглашения и санкции, господдержка и субсидии, документы, логистика, оценка «выгодно ли» и сравнение «куда ещё везти». Второй вход — слой «Где купить»: «Покупаю [товар] в [стране]» → регионы и кластеры производства, официальные реестры и выставки, без списков компаний (`docs/where-to-buy.md`). Полное описание — `docs/concept.md`. План работ — `docs/plan.md`. Санкционная политика — `docs/sanctions-policy.md`. Макеты интерфейса — `mockups/` (три HTML-страницы; фронтенд повторяет их структуру и стиль).

## Принципы, которые нельзя нарушать

1. Контент генерируется только из официальных источников из белого списка `data/sources.yaml`. Никогда не добавляй в конвейер блоги, форумы, сайты брокеров и перевозчиков.
2. Нет цитаты — нет утверждения. Каждый факт хранится с фрагментом текста источника, URL, датой снимка. Факт без цитаты не публикуется.
3. Ставки (пошлины, НДС, экспортные пошлины, преференции) берутся только из структурированных таблиц в `rates`. LLM никогда не «вспоминает» ставки и не пишет числа из своих знаний.
4. Никогда не выдумывай факты о правилах, программах или санкциях для заполнения пробелов. Если источника нет — статус `not_found`; если недоступен — `unavailable`. Это относится и к тестовым данным: тестовые фикстуры помечаются `is_demo = true`.
5. Санкции показываются как есть; никаких формулировок «как обойти». Любой текст для санкционных пар проходит проверку `pipeline/validate.py`.
6. Сайт не классифицирует товар точнее HS-6 и всегда отсылает к брокеру или предварительному решению таможни.
7. У каждой строки на странице — печать источника с датой и статусом (см. состояния в `docs/concept.md`, раздел 4).
8. Спрос и логистика в оценке — всегда «ориентир», никогда «проверено».

## Стек и структура

- `pipeline/` — Python 3.11+: реестр источников, загрузчик снимков, извлечение фактов через LLM API, слой ставок, валидаторы, сборщик страниц, индекс и оценка, монитор изменений.
- `web/` — Next.js + TypeScript, страницы по макетам из `mockups/`.
- `db/schema.sql` — PostgreSQL. Локально: Docker Compose или локальный Postgres.
- `data/sources.yaml` — белый список источников по странам (правится руками, это главный актив).
- `data/corridors.yaml` — коридоры MVP и товарные группы.
- Секреты — только в `.env` (шаблон `.env.example`), никогда в коде и коммитах.

## Как работать

- Сначала план, потом код: перед крупной задачей опиши подход в 5–10 строк и дождись «ок».
- Малые шаги с проверкой: каждый модуль конвейера должен запускаться отдельно на одном коридоре и одной товарной группе.
- Тесты для валидаторов обязательны: они — замена человеческой модерации.
- Не удаляй и не переписывай `docs/concept.md` без явной просьбы; при изменении решений добавляй запись в раздел «Что решено» с датой.
- Команды запуска добавляй сюда по мере появления (раздел ниже).

## Команды

    cp .env.example .env                      # секреты только здесь
    docker compose up -d                      # PostgreSQL 16 на localhost:5432; db/schema.sql применяется при первом старте
    docker compose down -v                    # сброс базы (том удаляется, схема применится заново)

    ./run-web.sh                              # то же одной командой (Windows: двойной клик по run-web.cmd)
    cd web && npm install && npm run dev      # сайт на http://localhost:3000 (демо-JSON из web/data/pages)
    cd web && npm run typecheck && npm run lint && npm run build   # то же гоняет CI (.github/workflows/ci.yml)

    python -m venv .venv && . .venv/bin/activate && pip install -e ".[dev]"   # конвейер
    python -m pipeline fetch --url <url из белого списка>                      # снимок в ./snapshots (хеш, дата)
    python -m pipeline monitor                                                # перечитать источники, проверить цитаты (без LLM)
    python -m pipeline validate                                               # валидаторы; тесты: python -m pytest pipeline/tests
    python -m pipeline extract --registry                                     # факты с цитатами из urls реестра, нужен ANTHROPIC_API_KEY
    #   модель вызывается только для изменившихся страниц; лимиты: PIPELINE_MAX_PAGES (40 страниц за запуск),
    #   PIPELINE_MAX_USD (5 $ за запуск), PIPELINE_MONTHLY_USD (15 $ в месяц, книга учёта data/usage.json); модель PIPELINE_MODEL
    python -m pipeline extract --registry --batch                             # то же через пакетный API за полцены (так работает daily-check.yml)
    #   отчёт о тратах каждого запуска — data/extract-report.md
    python -m pipeline supply --country CN --hs6 843280                       # слой «Где купить», заглушка
    python scripts/scaffold_demo_pages.py     # заготовки страниц для всех групп из data/corridors.yaml (демо, без выдуманных фактов)
    python -m pipeline reference                                              # data/hs6.json из UN Comtrade H6 (сеть: reference-data.yml)
    python -m pipeline rates --wits CA,CN                                     # data/rates/{ISO2}.json — MFN по HS-6 из WITS/TRAINS (сеть)
    python -m pipeline agreements                                             # data/agreements.json — РТС в силе из WTO RTA-IS (сеть); --between RU IR
    python -m pipeline index --from CN --to CA --hs6 610910                   # оценка из пяти частей и «куда ещё» из индексного слоя (без сети)
    python -m pipeline assemble                                               # факты + ставки + индекс → web/data/pages (daily-check.yml)
    python -m pipeline requests --sync --apply                                # очередь запросов коридоров из issues → data/requests.json, пустые страницы
    cd web && NEXT_PUBLIC_BASE_PATH=/Trade-Routes npm run build               # статический сайт в web/out (pages.yml публикует на GitHub Pages)

Шаблон страницы коридора как структура данных — `web/lib/page-content.ts` (`PageContent`); конвейер `assemble` выдаёт ровно эту форму. Шаблон страницы «где купить» — `web/lib/supply-content.ts` (`SupplyContent`), модуль `pipeline/supply.py`, таблицы `supply_regions` и `supply_pages`.

## Сеть

Из облачной сессии Claude Code официальные сайты (gc.ca, canada.ca, gov.cn, gov.ru, eaeunion.org, treasury.gov и др.) закрыты сетевой политикой: загрузчик и WebFetch получают 403 от egress-прокси. Не обходить. Реальные снимки и извлечение фактов запускаются из GitHub Actions (`daily-check.yml`) или с компьютера основателя.
