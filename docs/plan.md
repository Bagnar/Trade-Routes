# План работ

Отмечай выполненное `[x]`. Этапы идут последовательно; внутри этапа задачи можно параллелить.

## Этап 0 — подготовка (1–2 недели)

- [x] Инициализировать репозиторий (git), `.gitignore`, `.env.example` → `.env`.
- [x] Поднять PostgreSQL локально (Docker Compose) и применить `db/schema.sql`. (`docker-compose.yml`; схема проверена на PostgreSQL 16 и в CI.)
- [x] Каркас `pipeline/`: виртуальное окружение, зависимости (httpx, pydantic, psycopg, PyYAML, клиент LLM API), точка входа `python -m pipeline <команда>`. (`pyproject.toml`; модули — заглушки до этапа 1.)
- [x] Каркас `web/`: Next.js + TypeScript; перенести стили и структуру из `mockups/` в компоненты (шапка-запрос, полоса статуса, печать источника, карточка оценки, списки «выгодно/мешает», таблицы). (Сделано на демо-JSON двух коридоров, см. `web/README.md`.)
- [ ] Проверить и дополнить `data/sources.yaml`: для каждой записи открыть домен, подтвердить, что это официальный орган, найти конкретные страницы по темам (тарифы, лицензии, санкции, программы поддержки), заполнить `urls`.
- [ ] Утвердить списки товарных групп в `data/corridors.yaml` (10–12 на коридор), проверить коды HS-6.
- [ ] Загрузить структурированные ставки для первого коридора: канадский тариф по выбранным HS-6 (MFN и преференции), китайский экспортный контроль по группам; таблица `rates`.
- [ ] Написать `docs/sanctions-policy.md` до состояния, которое можно показать юристу (черновик есть).
- [x] Определить шаблон страницы коридора как структуру данных (JSON-схема блоков), совпадающую с макетами. (`web/lib/page-content.ts`, тип `PageContent`.)
- [x] Заготовки страниц для всех 24 товарных групп и «Где купить» для групп Китая и России (`scripts/scaffold_demo_pages.py`): структура сайта целиком, товарные факты — `not_found` до этапа 1.

## Этап 1 — конвейер на первом коридоре: Китай → Канада (2–3 недели)

- [x] `fetch`: загрузка страниц только из реестра, снимки с хешем и датой, повторные попытки, лимиты вежливости. (`pipeline/fetch.py`, `registry.py`.)
- [x] `extract`: из снимка — факты по блокам с цитатой, URL, языком; отбрасывание фактов без цитаты; тесты. (`pipeline/extract.py`; запуск из GitHub Actions с `ANTHROPIC_API_KEY`.)
- [ ] `rates`: подстановка ставок из таблицы в факты о пошлинах и налогах; запрет чисел из LLM; тесты.
- [~] `validate`: белый список, цитаты, числа без ссылки на ставки, формулировки для санкционных пар — сделано с тестами (`pipeline/validate.py`); санкционная проверка пары и полнота блоков — впереди.
- [ ] `assemble`: сборка страницы из фактов по шаблону; русский и английский из одного набора фактов; печати источников со статусами.
- [ ] Прогнать 3 товарные группы (футболки, обувь, мебель) и разобрать результат руками; исправить извлечение и валидаторы.
- [ ] Калькулятор «сколько платить» — правила расчёта для Канады (пошлина, GST, HST для посылок).
- [ ] «Где купить», первый набор: `supply` — регионы и кластеры Китая по 2–3 группам (трикотаж 6109, сельхозтехника 8432–8436) из stats.gov.cn, miit.gov.cn, mofcom.gov.cn; официальные реестры и выставки; показатели только из статистических таблиц; тесты «нет компаний в тексте».
