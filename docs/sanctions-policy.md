# Санкционная политика сайта — черновик для юриста

Статус: черновик, 6 сентября 2026. Показать юристу по санкциям до публичного запуска санкционных коридоров.

## Что делает сайт

1. Для каждой пары стран конвейер проверяет санкционные режимы Канады, США, ЕС и Великобритании, а также режимы самих стран пары, по официальным источникам из реестра (`data/sources.yaml`, раздел `sanctions_authorities`).
2. Результат проверки имеет один из статусов: товар запрещён; запрещены сделки с лицами из списков; ограничены расчёты и услуги (страхование, перевозка); отраслевые ограничения; ограничений нет.
3. Если товар запрещён — красный статус, оценка коридора 0, страница описывает запрет и его источник.
4. Если запрещены лица или ограничены расчёты — красная полоса «Санкционный коридор» и препятствие в оценке; текст описывает, что именно ограничено, кем, с какой даты и где это проверить.
5. Все страницы санкционных пар содержат требование проверить контрагента, его банк и судно по спискам до сделки и перед каждой отгрузкой.

## Чего сайт не делает

1. Не описывает способы обхода ограничений: схемы расчётов, посредников, переоформление происхождения, флаги судов, «дружественные» банки. Валидатор конвейера отбрасывает формулировки такого рода; список запрещённых конструкций ведётся в `pipeline/validate.py`.
2. Не даёт оценки законности конкретной сделки и не подбирает контрагентов.
3. Не хранит и не публикует данные о конкретных компаниях и лицах, кроме ссылок на официальные списки.
4. Не сравнивает санкционные режимы по «удобству» и не рекомендует юрисдикцию для обхода.

## Оператор

Оператор сайта находится в Канаде и подпадает под канадское санкционное право. Публикация регуляторной информации и содействие сделкам — разные вещи; граница между ними для персонализированных страниц и уведомлений — предмет консультации с юристом.

## Вопросы юристу

- Достаточно ли текущей формулировки условий использования и дисклеймеров для персонализированных страниц по санкционным парам.
- Нужно ли ограничивать подписку на уведомления по санкционным коридорам или содержание этих уведомлений.
- Какие товарные группы для пар Россия — Иран, Китай — любая страна требуют особой осторожности (двойное назначение, экспортный контроль).
- Порядок действий, если пользователь сообщает о намерении нарушить санкции.
