# Слой «Где купить» — регионы производства и официальные способы найти поставщика

Статус: решено 12 сентября 2026 (`docs/concept.md`, «Что решено», п. 10). Реализация — демо на этапе 0, данные конвейера — этапы 1–3 (`docs/plan.md`).

## Запрос

«Покупаю [товар HS-4/HS-6] в [стране]». Ответ — страница «где купить»: в каких регионах, провинциях и кластерах страны производят этот товар, через какие официальные реестры, выставки и агентства искать поставщиков, что проверить до сделки, и куда из этой страны этот товар выгодно везти (ссылки на страницы коридоров).

Примеры: сельхозтехника в Китае → провинции с кластерами машиностроения; трикотаж в Турции → провинции с текстильными промзонами.

## Что показывает страница

1. **Шапка**: фраза-запрос, язык.
2. **Полоса статуса**: источники, дата, дисклеймер.
3. **Коротко**: главные регионы, где искать, что проверить.
4. **Регионы и кластеры** (таблица): регион — что производят и чем известен — показатель из статистики — печать источника.
5. **Как найти поставщика**: только официальные реестры промзон и кластеров, государственные выставки, экспортные агентства, торгпредства.
6. **Что проверить до покупки**: лицензии на вывоз из этой страны, сертификаты, санкционные и «принудительный труд» проверки, ссылка на брокера.
7. **Куда везти**: открытые коридоры вывоза из этой страны для этой группы.
8. **Источники и проверка**.

## Правила (в дополнение к `CLAUDE.md`)

1. **Только регионы и официальные реестры.** Конкретные компании, их контакты и рейтинги не публикуются (см. `docs/sanctions-policy.md`, «Чего сайт не делает»). Валидатор отбрасывает факты с названиями компаний.
2. **Показатели — только из статистических таблиц.** Доля региона в выпуске, число предприятий, объём экспорта из провинции берутся из данных статистических служб (`regional_output`, `trade_stats`) так же, как ставки из `rates`. LLM не пишет эти числа.
3. **Источники**: статистические службы, министерства промышленности и торговли, реестры промзон, государственные выставочные организации, экспортные агентства — записи с темами `supply_regions`, `industrial_clusters`, `industrial_zones`, `regional_output`, `supplier_directory`, `trade_fairs` в `data/sources.yaml`. Отраслевые ассоциации и коммерческие выставки — только если это государственный орган или организация, созданная законом; иначе не входят.
4. **Пробелы честные.** Если по региону нет статистики — показатель «не загружено», не догадка.
5. **Не рекомендация.** Список регионов — навигация к первоисточникам, не оценка качества поставщиков.

## Данные

- Таблица `supply_regions` (`db/schema.sql`): страна, регион, охват HS, вид записи (кластер, промзона, статистика выпуска, реестр/выставка), цитата, источник, снимок, статус, `is_demo`.
- Таблица `supply_pages`: собранные страницы (JSONB `content`) по (страна, HS, язык), как `pages` для коридоров.
- Шаблон содержимого — `web/lib/supply-content.ts` (`SupplyContent`).
- Демо-фикстуры — `web/data/supply/*.json`, все `isDemo: true`, печати со статусом «требует проверки»: конвейер ещё не перечитывал источники.
- Модуль конвейера — `pipeline/supply.py`: `python -m pipeline supply --country CN --hs6 843280`.

## Открытые вопросы

- Турция не входит в коридоры MVP; её источники внесены в реестр как `to_verify` только для этого слоя.
- Уровень HS для «где купить»: HS-4 (группа отрасли) удобнее, чем HS-6; страница принимает оба.
- Нужен ли слой для страны ввоза (кто в Канаде импортирует) — пока нет.
