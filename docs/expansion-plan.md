# План расширения: все страны, все товары, законы и справочная информация

Решение от 12 сентября 2026 (`docs/concept.md`, «Что решено», п. 12): сайт — бесплатный информационный портал для начинающих
торговцев и поставщиков по всем странам и всем товарным группам. Принципы `CLAUDE.md` (только официальные источники,
нет цитаты — нет утверждения, ставки только из таблиц, санкции как есть) не меняются: меняется охват, не честность.

Как это возможно без миллионов страниц: **справочники заранее, страницы по запросу.** Страны, товарная номенклатура,
ставки, соглашения и санкционные режимы загружаются целиком из структурированных официальных баз — это дешёвый
индексный слой. Полная страница коридора собирается только когда её спросили, кэшируется и дальше проверяется
ежедневно.

## 1. Что делаю я сам (без денег и без ручной работы основателя)

| # | Что | Результат |
|---|---|---|
| 1.1 | Полный список стран (ISO 3166-1, ~250) с русскими формами «из …», «в …», «в …е» | оба поиска работают для любой пары стран; для неоткрытой пары — честный ответ и запись запроса |
| 1.2 | Полная номенклатура HS-6 (~5 600 групп) с названиями на английском из официальной базы ООН (UN Comtrade reference) и на русском из ТН ВЭД ЕАЭС (ЕЭК); поиск по словам («дрон» → 8806, «трактор» → 8701) | любой товар находится кодом |
| 1.3 | Загрузчик ставок MFN по HS-6 для всех членов ВТО из WTO Tariff Download Facility (официальная база ВТО) в таблицу `rates` | ставка ввоза для любой пары «страна — группа» без участия модели |
| 1.4 | Загрузчик торговых соглашений из базы РТС ВТО и санкционных режимов (Канада, США, ЕС, Великобритания) по официальным спискам | индексный слой «соглашение есть/нет», «санкции есть/нет» для всех пар |
| 1.5 | Сборщик страниц: факты из `data/facts` попадают на страницы коридоров по стране и HS; печати с цитатой и датой | извлечённое становится видно там, где нужно |
| 1.6 | Индекс и оценка из пяти частей для всех пар по индексному слою; таблица «куда ещё везти» | сравнение направлений для любого товара |
| 1.7 | Блок «Экспортный контроль и двойное назначение» в шаблоне страницы (дроны, электроника, химия, станки) с источниками — контрольные списки Канады, ЕС, США, Вассенаарские договорённости | ограничения показываются как есть |
| 1.8 | Страница «Законы и органы» по стране: перечень актов и ведомств из реестра с ссылками | вход для тех, кто хочет читать первоисточник |
| 1.9 | Очередь запросов коридоров: кнопка «Запросить коридор» сохраняет запрос (через GitHub без сервера), конвейер собирает страницы по очереди | рост по спросу, не по догадке |
| 1.10 | Черновики реестров источников для новых стран (домены официальных органов, статус `to_verify`) | основателю остаётся проверить, а не искать |
| 1.11 | Развёртывание: конфигурация для бесплатного хостинга, ежедневная пересборка сайта из репозитория | сайт доступен всем, а не только локально |

Порядок: 1.1–1.2 → 1.5 → 1.3–1.4 → 1.6 → 1.7–1.9 → 1.10–1.11. Каждый пункт — отдельный коммит с тестами.

## 2. Что требует денег

| Статья | Когда | Сколько (ориентир) |
|---|---|---|
| Извлечение фактов Claude API | первый проход по реестру каждой страны | 2–4 $ на страну (10–20 страниц); повторно только при изменении страниц |
| Сборка текста страницы коридора по запросу (плоский язык, второй язык) | при первом запросе страницы | 0,05–0,15 $ за страницу; кэшируется |
| Русские названия HS-6, если ТН ВЭД ЕАЭС окажется без машиночитаемой выгрузки | один раз | 3–5 $ (перевод 5 600 коротких строк) |
| Торговая статистика UN Comtrade (часть «спрос») | этап 2 | бесплатный ключ с лимитом запросов; платный тариф только при большой нагрузке |
| Хостинг сайта | публичный запуск | бесплатный тариф (некоммерческий сайт); домен 10–20 $ в год |
| База данных | когда файлы в репозитории перестанут вмещать | бесплатный тариф управляемого Postgres; до этого — JSON в git |
| GitHub Actions | ежедневно | бесплатно для публичного репозитория |
| Юрист по санкциям и двойному назначению | до публичного запуска санкционных и дроновых страниц | по договорённости; единственная крупная статья |

Ориентир на первые месяцы: 10–30 $ в месяц на API при добавлении 2–5 стран в месяц; в спокойные дни — около нуля.
Предохранители уже стоят: неизменённые страницы к модели не отправляются, лимит вызовов за запуск, предоплатные кредиты
без автопополнения.

## 3. Что нужно сделать руками основателю

1. **Проверить реестры источников.** Для каждой страны открыть каждую запись `data/sources.yaml`, подтвердить, что домен
   принадлежит официальному органу, поставить `status: verified` или удалить. Черновики готовлю я; проверка — 15–30 минут
   на страну. Это единственный ручной актив, который нельзя делегировать модели.
2. **Задать порядок стран и товаров.** Назвать первые 5–10 стран и 10–20 групп, важных для начинающих. Дальше — по очереди
   запросов с сайта.
3. **Аккаунты и ключи.** Кредиты Anthropic (сделано); бесплатный ключ UN Comtrade; аккаунт хостинга; домен; название сайта.
4. **Прочитать первые страницы каждой новой страны.** Это отладка конвейера, не модерация: 20 минут на страну, ошибки —
   мне в чат.
5. **Юрист.** Санкционные коридоры и товары двойного назначения (дроны, электроника, станки) — до публичного показа.
6. **Условия использования и дисклеймер** на сайте перед публичным запуском.

## Чего не будет и почему

- Сайт не назовёт код точнее HS-6 и не станет консультацией — принцип 6.
- Страницы для пар без проверенных источников не появятся: будет честный статус «источники не проверены».
- Инструкций «как обойти» ограничения не будет ни для одной страны — принцип 5, валидатор их отбрасывает.
