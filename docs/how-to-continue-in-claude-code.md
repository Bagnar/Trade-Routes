# Как продолжить работу в Claude Code

Этот репозиторий — перенос всего, что решено в чате: концепт (`docs/concept.md`), правила для Claude (`CLAUDE.md`), план (`docs/plan.md`), реестр источников (`data/sources.yaml`), коридоры (`data/corridors.yaml`), схема базы (`db/schema.sql`), макеты (`mockups/`).

История чата в Claude Code не переносится — переносятся файлы. Всё, что должно быть известно Claude в проекте, живёт в `CLAUDE.md` и `docs/`.

## Первые шаги

1. Установить Claude Code (терминал, VS Code или приложение Claude Desktop, вкладка Code): https://code.claude.com/docs/en/overview
2. Распаковать этот архив в папку проекта и открыть её в Claude Code.
3. Первый запрос Claude Code (скопировать):

   > Прочитай CLAUDE.md, docs/concept.md и docs/plan.md. Кратко перескажи, что за проект и какие принципы нельзя нарушать, чтобы я убедился, что ты всё понял. Потом предложи план на первые две задачи этапа 0: репозиторий с .gitignore и .env, и PostgreSQL через Docker Compose с применением db/schema.sql. Ничего не делай, пока я не скажу «ок».

4. Дальше — по `docs/plan.md`, задача за задачей. Полезные запросы:

   > Выполни следующую невыполненную задачу этапа 0 из docs/plan.md, отметь её [x] после проверки.

   > Проверь реестр data/sources.yaml: открой каждый домен, подтверди, что это официальный орган, найди страницы по темам и заполни urls. Ничего не придумывай — если страницу найти не удалось, оставь пусто и напиши почему.

   > Собери каркас web/ на Next.js и перенеси стили и структуру из mockups/corridor-china-canada.html в компоненты. Пока без данных — покажи страницу на демо-JSON.

5. Когда появятся команды запуска, добавляй их в раздел «Команды» файла `CLAUDE.md`.

## Переезд на сервер (этап 3)

Стек переезжает без переписывания: Next.js — на любой хостинг Node или Vercel; PostgreSQL — управляемая база или свой сервер; конвейер — планировщик на том же сервере. Домен и HTTPS — при аренде. До этого всё работает локально.
