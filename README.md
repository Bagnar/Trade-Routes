# Справочник правил международной торговли — стартовый набор проекта

Перенос всего, что решено в обсуждении, в форму, с которой можно начинать разработку.

- `CLAUDE.md` — контекст и правила для Claude Code (читается первым).
- `docs/concept.md` — концепт продукта, версия 2 (что решено, страница, оценка, данные, архитектура, MVP, дорожная карта).
- `docs/plan.md` — план работ по этапам с задачами.
- `docs/sanctions-policy.md` — санкционная политика, черновик для юриста.
- `docs/expansion-plan.md` — план расширения на все страны и товары: что делает Claude, что стоит денег, что делает основатель (12 сентября 2026).
- `docs/where-to-buy.md` — слой «Где купить»: регионы производства и официальные способы найти поставщика (решено 12 сентября 2026).
- `docs/how-to-continue-in-claude-code.md` — как продолжить работу в Claude Code, первые запросы.
- `data/sources.yaml` — белый список официальных источников по странам (главный ручной актив).
- `data/corridors.yaml` — коридоры MVP и предлагаемые товарные группы.
- `db/schema.sql` — схема PostgreSQL.
- `pipeline/` — каркас конвейера (модули с описанием, без реализации); зависимости в `pyproject.toml`.
- `docker-compose.yml` — локальный PostgreSQL 16 с автоматическим применением схемы.
- `.github/workflows/ci.yml` — проверка сборки веба, синтаксиса конвейера и схемы базы.
- `web/` — Next.js-приложение по макетам: стартовая и страницы коридоров на демо-JSON (`web/README.md`).
- `mockups/` — три HTML-макета: стартовая, Китай → Канада, Россия → Иран.

Начало работы — `docs/how-to-continue-in-claude-code.md`. Быстрый запуск сайта — `./run-web.sh` (Windows: `run-web.cmd`).
